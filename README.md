# マンホールカードマップ

マンホールカードの配布場所を地図で確認する静的Webサイトです。地図上のピンを選ぶと配布場所、住所、経路、公式情報へのリンクを確認できます。

## データ

- 表示データは `data/cards.csv` と `data/cards-02.csv`〜`data/cards-14.csv` から読み込みます。各CSVは同じ列構成で、合わせて1,332件を収録しています。編集するときは対象行の入ったCSVを変更してください。
- 元データの1,332件を登録しています。元CSVの発行年月日・市町村・弾数・建物名・住所を `元データ_*` 列にも保存しています。
- 緯度・経度は国土地理院の住所検索結果を登録しています。住所が十分でない地点も含むため、座標確認欄はすべて「未確認」です。住所や座標を確認後、CSV上で編集してください。
- CSVを編集するときはUTF-8で保存し、列名を維持してください。変更をGitHubにコミットすると、公開サイトはそのCSVを読み込みます。
- 詳細リンクは画面上で共通の「詳細」と表示されます。

## 公開

GitHubとCloudflare Pagesで公開できます。ビルドコマンドは空欄、出力ディレクトリはリポジトリのルートです。HTML、CSS、JavaScript、CSVだけで動作します。

## ローカルで確認

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。地図にはOpenStreetMap由来のデータを使ったOpenFreeMapを使用しています。地図上の著作権表示を消さないでください。
