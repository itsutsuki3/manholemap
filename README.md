# マンホールカードマップ

マンホールカードの**配布場所**と、実際の**マンホール蓋の設置場所**を地図で確認する静的Webサイトです。
ビルド不要（HTML / CSS / JavaScript / JSON のみ）。Cloudflare Pages の Direct Upload でそのまま公開できます。

> `data/cards.csv` の中身は**動作確認用の架空データ**です（名称に【架空サンプル】と付いています）。実在の場所・座標ではありません。公開前に実データへ置き換えてください。

## ファイル構成

```
index.html          画面
css/style.css       スタイル
js/app.js           地図・ピン・詳細パネル・現在地・取得済み管理
data/cards.csv      カードデータ（CSV）
images/cards/       カード画像（現在は架空のサンプルSVG）
```

## 使い方

- 初期表示は「カード配布場所」。上部のボタンで「蓋の設置場所」に切り替えます。
- ピンをタップすると詳細パネルが開きます（経路は Google Maps / Apple Maps で開けます）。
- 「取得済み」にチェックすると、そのカードの配布場所・蓋設置場所の両方のピンがグレーになります。状態はブラウザのLocalStorage（キー `manholeMap.collected.v1`）に保存され、再読み込み後も維持されます。端末・ブラウザごとの保存で、他の端末とは同期しません。
- ピンを開いて「写真を撮影」を押すと、カメラで撮った写真がそのカードの画像（ピンとパネル）になります。写真はこの端末のブラウザ内（IndexedDB）にだけ保存されます。
- 右下のボタンで現在地を表示します。許可されない・取得できない場合も地図はそのまま使えます。

## ローカルで確認する

`index.html` をダブルクリックで開くと、データを読み込めません。簡易サーバー経由で開いてください。

```
python3 -m http.server 8000
# http://localhost:8000 を開く
```

現在地の取得はHTTPSまたは `localhost` でのみ動作します（Cloudflare PagesはHTTPSです）。

## Cloudflare Pages へのデプロイ（Direct Upload）

1. Cloudflare ダッシュボードにログインし、Workers & Pages から Pages プロジェクトを新規作成し、「Direct Upload（直接アップロード）」を選びます（メニュー名は変更されることがあります）。
2. プロジェクト名を入力します。
3. このZIPを展開したフォルダ（`index.html` がその直下にあること）をアップロードします。ZIPのままアップロードする場合も、`index.html` がZIPの直下にある状態です。
4. 「Deploy」後に発行されるURL（`https://プロジェクト名.pages.dev`）で確認します。

更新するときは、プロジェクトの「新しいデプロイを作成」から同じ手順で再アップロードします。
CLIを使う場合: `npx wrangler pages deploy . --project-name <プロジェクト名>`（ビルド設定は不要）

## データの追加方法（CSV）

`data/cards.csv` を表計算ソフトやテキストエディタで編集し、サイトを再アップロードするだけで反映されます（変換作業は不要です）。1行が1枚のカードです。
平日と休日などで場所が違う場合は、別のカード（別のID・別の行）として登録してください。

| 列 | 内容 |
|---|---|
| カードID | 一意のID。半角英数字とハイフン推奨（例: 01-201-001）。**一度決めたら変えない**（取得済み・写真がIDに紐づくため） |
| カード名称 / 都道府県 / 市区町村 / 弾数 | 文字データ |
| カード画像URL | 空でも可（下記「画像」参照） |
| 配布場所名称 / 配布場所住所 / 配布場所緯度 / 配布場所経度 | **緯度・経度は必須**（数値）。無い行は読み込まれません |
| 蓋設置場所名称 / 蓋設置場所住所 / 蓋緯度 / 蓋経度 | 不明なら空欄。空欄なら蓋側の地図にピンは出ません |
| 出典URL / 情報確認日 | 出典のURL、確認日（例: 2026-11-22） |
| 配布座標確認 / 蓋座標確認 | `確認済み` / `未確認` / `架空` のいずれか（空欄は未確認） |
| 架空サンプル | `○` を入れると「架空データ」の注意書きが出ます。実データでは空欄 |

- 1行目の列名は変えないでください（列の順番は自由）。サンプル3行は削除して構いません。
- 文字コードはUTF-8を推奨します。Excelで保存した通常のCSV（Shift_JIS）も自動で読み込みます。
- 住所や名称にカンマや改行を含める場合は、その項目を `"` で囲みます（表計算ソフトが自動で行います）。
- 緯度・経度は、Google Mapsで場所を長押し（右クリック）すると表示される数値をコピーできます。座標・住所は公式情報で確認し、出典と確認日を記録してください。
- 読み込めない行（ID重複・必須項目なし・座標が不正）があると、画面に行番号つきのメッセージが出ます。

## 画像（写真）

- **スマホで撮影**: ピンを開き「写真を撮影」を押すと、カメラで撮った写真が登録されます（長辺720pxに縮小）。
  この写真は**撮影した端末のブラウザにだけ**保存され、他の端末や他の訪問者には表示されません。
  iPhoneのSafari系ブラウザは、一定期間（目安7日）サイトを開かないと保存データを消すことがあります。消えて困る写真は、下の方法でサイトに載せてください。
- **まとめてダウンロードして再アップロード**: 写真を撮ると、地図の左上にダウンロードボタン（撮影枚数つき）が出ます。押すと、この端末の全写真が `images/cards/<カードID>.jpg` の構成のZIPになります。展開してできた `images` フォルダを、プロジェクトの `images` フォルダに入れて再アップロードすると、全員に表示されます。他の端末で撮った写真は、その端末でダウンロードしてください（CSVは含まれないので、手元の編集が上書きされることはありません）。
- **1枚ずつ書き出す**: 詳細パネルの「写真を書き出す」で `ID.jpg` を保存し、`images/cards/` に入れて再アップロードします。`カード画像URL` が空なら、`images/cards/<カードID>.jpg` が自動で使われます。
- 表示の優先順位: この端末で撮った写真 → CSVのカード画像URL → `images/cards/<カードID>.jpg`。
- 取得済みチェックも同じくブラウザ内保存です。

## 利用条件・権利について

- **地図**: OpenStreetMapのデータを使った無料のベクタ地図配信サービス「OpenFreeMap」（`tiles.openfreemap.org`、APIキー不要）を使用しています。地図右下の「© OpenStreetMap contributors」等の表記は消さないでください（OSMのデータはODbLで、表示が必須です）。デザインは `js/app.js` 冒頭の `STYLE_URL` で `bright` / `liberty` / `positron` から変更できます。無保証の無料サービスなので、利用条件とサービスの継続性を公開前に確認してください（https://openfreemap.org ）。OSM公式のタイルサーバー（tile.openstreetmap.org）は大量利用に向かないため使っていません。
- **MapLibre GL JS**: `unpkg.com` からバージョン固定（4.7.1）で読み込みます。ライセンスはBSD-3-Clauseです。外部CDNに頼りたくない場合は、同じバージョンのJS/CSSを `vendor/` に置き、`index.html` の参照先を書き換えてください。
- **Geolocation API**: ブラウザ標準機能です。位置情報はこのサイトのサーバーへ送信されず、端末内で地図表示に使うだけです。
- **経路**: Google Maps / Apple Maps のURLを開くだけで、APIキーは使いません。各サービスの利用規約に従います。
- **カード画像**: 公式画像の著作権は自治体・関係団体等にあります。`images/README.md` を参照し、掲載前に利用条件を確認してください。
- 上記の条件は変更されることがあります。公開前に最新の内容を確認してください。

## 動作確認チェックリスト

デプロイ後、スマートフォンで以下を確認してください。

1. 地図が表示される（地図サービスに接続できない環境では表示されません）
2. 現在地ボタンで現在地が表示される（許可を拒否した場合はメッセージが出て、地図は使える）
3. 「カード配布場所」「蓋の設置場所」を切り替えられる
4. ピンをタップすると詳細パネルが開く
5. 「取得済み」チェックが再読み込み後も残る
6. チェックしたカードのピンが、配布場所・蓋設置場所の両方でグレーになる
7. 「Google Mapsで経路」が目的地付きで開く
