# マンホールカードマップ

マンホールカードの**配布場所**と、実際の**マンホール蓋の設置場所**を地図で確認する静的Webサイトです（HTML / CSS / JavaScript / CSV、ビルド不要）。
GitHubリポジトリに置き、Cloudflare PagesのGit連携でデプロイします。作成者はサイト上でカードの追加・編集・写真撮影ができ、保存するとGitHubに自動で反映されます。

> `data/cards.csv` の中身は**動作確認用の架空データ**です（名称に【架空サンプル】と付いています）。公開前に実データへ置き換えてください。

## ファイル構成

```
index.html          画面
css/style.css       スタイル
js/app.js           地図・ピン・詳細パネル・現在地・取得済み管理・作成者モード
data/cards.csv      カードデータ（これが唯一のデータ。デプロイするのはこのファイルだけでも可）
images/cards/       カード画像（<カードID>.jpg）
```

## 公開（GitHub + Cloudflare Pages）

1. GitHubにリポジトリを作り、このZIPの中身を全部アップロードします（最初の1回だけ）。
2. Cloudflare Pages で「Gitに接続」を選び、そのリポジトリを指定します。
3. ビルドコマンドは空欄、出力ディレクトリは `/`（ルート）にします（画面の表記は変わることがあります）。
4. 以降は、リポジトリにファイルが追加・変更されるたびに自動でデプロイされます（通常1〜2分）。

**データだけの更新でも問題ありません。** 変更したファイル（`data/cards.csv` や `images/cards/*.jpg`）だけをGitHubにコミットすれば、サイト全体が自動で再デプロイされます。ZIPを毎回作り直す必要はありません。GitHubのWeb画面の「Add file → Upload files」からでも更新できます。

## 作成者モード（サイト上で追加・編集・写真登録）

公開サイトを開いたまま、データを直接編集して保存できます。保存の中身は、GitHubへの `data/cards.csv` や写真のコミットです。

### 初回設定

1. GitHubの Settings → Developer settings → Personal access tokens → Fine-grained tokens で、**このリポジトリだけ**を対象に、Repository permissions の **Contents を Read and write** にしたトークンを作ります（期限は任意）。
2. スマホ（または編集に使う端末）で、サイトのURLの末尾に `?admin=1` を付けて開きます（例: `https://xxxx.pages.dev/?admin=1`）。この端末は以後、作成者モードになります。戻すには `?admin=0` を付けて開きます。
3. 左上の ⚙ を押し、ユーザー名・リポジトリ名・ブランチ名・トークンを入力して「保存して接続テスト」を押します。

### 使い方

- **カードを追加**: 地図を追加したい場所の近くに動かして、左上の ＋ を押します。地図の中心が配布場所の座標に入ります。「現在地を入力」でも入れられます。Google Mapsの座標（`35.68,139.76` の形）は緯度の欄にそのまま貼り付けられます。
- **編集・削除**: ピンを開き「カード情報を編集」を押します。
- **写真を登録**: ピンを開き「写真を撮影」を押してカメラで撮ります。長辺720pxに縮小され、`images/cards/<カードID>.jpg` としてGitHubに保存されます。
- 保存すると、**この画面にはすぐ反映**されます。公開サイトへの反映は、デプロイ完了後（1〜2分）です。その間にページを再読み込みすると、写真だけ古い状態に見えることがあります。
- 平日と休日などで場所が違う場合は、別のカード（別ID）として登録してください。

### 安全上の注意

- `?admin=1` は表示を切り替えるだけで、鍵ではありません。書き込みを守っているのは**トークン**です。トークンはこの端末のブラウザ内にだけ保存され、サイトやリポジトリには含まれません。
- 他人に端末を使わせる場合や、紛失したときは、GitHubでトークンを削除してください。トークンは対象リポジトリとContents権限だけに絞ってください。
- リポジトリを公開にしている場合、CSVも写真も誰でも見られます。
- GitHub未設定でも、作成者モードで撮った写真はこの端末にだけ保存されます（左上のダウンロードボタンでZIPにして、`images` フォルダに追加できます）。

## データ（CSV）を直接編集する場合

`data/cards.csv` を表計算ソフトやテキストエディタで編集して、GitHubにコミットしても構いません。1行が1カードです。

| 列 | 内容 |
|---|---|
| カードID | 一意のID。半角英数字とハイフン推奨。**一度決めたら変えない**（取得済み・写真がIDに紐づくため） |
| カード名称 / 都道府県 / 市区町村 / 弾数 | 文字データ |
| カード画像URL | 空でも可（下記「画像」参照） |
| 配布場所名称 / 配布場所住所 / 配布場所緯度 / 配布場所経度 | **緯度・経度は必須**（数値） |
| 蓋設置場所名称 / 蓋設置場所住所 / 蓋緯度 / 蓋経度 | 不明なら空欄。空欄なら蓋側の地図にピンは出ません |
| 出典URL / 情報確認日 | 出典のURL、確認日（例: 2026-11-22） |
| 配布座標確認 / 蓋座標確認 | `確認済み` / `未確認` / `架空` のいずれか（空欄は未確認） |
| 架空サンプル | `○` を入れると「架空データ」の注意書きが出ます。実データでは空欄 |

- 1行目の列名は変えないでください（列の順番は自由）。サンプル3行は削除して構いません。
- 文字コードはUTF-8を推奨します。Excelの通常のCSV（Shift_JIS）も自動で読み込みます。
- 読み込めない行（ID重複・必須項目なし・座標が不正）があると、画面に行番号つきのメッセージが出ます。
- 座標・住所は公式情報で確認し、出典と確認日を記録してください。

## 画像

表示する画像は、次の優先順位で探します。

1. 作成者モードで今撮った写真（その画面の中だけ）
2. `images/cards/<カードID>.jpg`
3. CSVの `カード画像URL`

公式のカード画像の著作権は自治体・関係団体等にあります。掲載前に利用条件を確認してください（`images/README.md` 参照）。

## 使い方（閲覧者）

- 初期表示は「カード配布場所」。上部のボタンで「蓋の設置場所」に切り替えます。
- ピンをタップすると詳細パネルが開きます。経路はGoogle Maps / Apple Mapsで開けます。
- 「取得済み」にチェックすると、配布場所・蓋設置場所の両方のピンがグレーになります。状態はブラウザ内（LocalStorage）に保存され、他の端末とは同期しません。
- 右下のボタンで現在地を表示します。許可されない・取得できない場合も地図は使えます。
- 重なったピンは、南が手前、取得済みが奥、選択中が最前面になります。

## ローカルで確認する

`index.html` を直接開くとデータを読み込めません。簡易サーバー経由で開いてください。

```
python3 -m http.server 8000
# http://localhost:8000 を開く
```

現在地の取得とカメラはHTTPSまたは `localhost` でのみ動作します（Cloudflare PagesはHTTPSです）。

## 利用条件・権利について

- **地図**: OpenStreetMapのデータを使った無料のベクタ地図配信サービス「OpenFreeMap」（`tiles.openfreemap.org`、APIキー不要）を使用しています。地図左下の「© OpenStreetMap contributors」等の表記は消さないでください（OSMのデータはODbLで、表示が必須です）。デザインは `js/app.js` 冒頭の `STYLE_URL` で `bright` / `liberty` / `positron` から変更できます。無保証の無料サービスなので、利用条件とサービスの継続性を公開前に確認してください（https://openfreemap.org ）。
- **MapLibre GL JS**: `unpkg.com` からバージョン固定（4.7.1）で読み込みます。ライセンスはBSD-3-Clauseです。外部CDNに頼りたくない場合は、同じバージョンのJS/CSSを `vendor/` に置き、`index.html` の参照先を書き換えてください。
- **GitHub API**: 作成者モードで `api.github.com` を呼び出します。利用はGitHubの利用規約に従い、APIの利用制限があります。
- **Geolocation API / カメラ**: ブラウザ標準機能です。位置情報や写真は、保存操作をしない限りどこにも送信されません。
- **経路**: Google Maps / Apple Maps のURLを開くだけで、APIキーは使いません。
- 上記の条件は変更されることがあります。公開前に最新の内容を確認してください。

## 動作確認チェックリスト

デプロイ後、スマートフォンで確認してください。

1. 地図が表示される
2. 現在地ボタンで現在地が表示される（許可を拒否してもメッセージが出て地図は使える）
3. 「カード配布場所」「蓋の設置場所」を切り替えられる
4. ピンをタップすると詳細パネルが開く
5. 「取得済み」チェックが再読み込み後も残り、両方のピンがグレーになる
6. 「Google Mapsで経路」が目的地付きで開く
7. （作成者）`?admin=1` で、追加・編集・写真撮影が保存でき、1〜2分後に公開サイトに反映される
